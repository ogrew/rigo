# データの出典確認・更新手順

公開データの出典とライセンスは `THIRD_PARTY_NOTICES.md` に記録する。データを更新するときは、以下の手順で確認する。

1. KANJIDIC2 の公式配布と kanji-data の変更履歴を定期的に確認する。EDRDG は更新手順を設けるよう求めている。月1回の確認を目安とし、確認日と結果を記録する。
2. 入力ファイルの取得元 URL、commit またはリリース番号、取得日、SHA-256、ライセンス原文を作業用ディレクトリに保存する。
3. 再生成の前に、現在公開している JSON と生成スクリプトを保存する。データに実質的な更新がある場合は、変更範囲を確認してから再生成する。
4. 字の件数、筆画、部品、読み・意味、Auto と Export の動作を比較する。データの変化が作品に影響する場合は、その内容を記録する。
5. 加工日と加工内容、出典・ライセンス、再生成に使った版を更新し、文書とデータを同じコミットで公開する。

2026-11-26 に入力との照合とライセンス文書を整備し、その後、未使用の `op` を `kvg_all.json` と生成スクリプトから削除した。他の JSON 項目の値は変更していない。データ全体は再生成していない。定期確認の自動実行は設定していない。
